# Neon Drift: Fracture

An original twin-stick arena shooter where a cyan interceptor survives escalating geometric storms. Move with WASD or arrows, aim with the mouse, and hold click or Space to fire. Collect shield and rapid-fire drops, build a combo, and survive as many waves as possible. P or Escape pauses, M mutes, and R restarts.

Run locally with `node serve.ts`, then open `http://localhost:8080`.
